# Panvel Desktop

A GPU-accelerated modular desktop overlay engine built with Rust, inspired by the idea of composable desktop widgets.

Panvel focuses on layered, panel-based components: custom dashboards, real-time data gauges, waveform visualizations, translucent floating panels with soft shadows and blur effects.

> The name Panvel is repurposed from a geographic name. We interpret it as **Panel + Vel (Layer)** — stacked, assembleable overlay panels.

⚠️ This project is under active development. Not ready for daily use yet.

## Features (WIP)
- Modular, splittable panel components
- GPU rendering powered by wgpu
- Custom skin / widget configuration
- Real-time data visualization (graphs, waveform, meters)
- Translucent, blurred overlay panels

## Goals
Provide a lightweight, high-performance alternative desktop widget engine, fully written in Rust.
